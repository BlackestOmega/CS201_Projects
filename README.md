# CS201_Projects

## Project 3

### Requirements

- **g++** 9 or newer (C++17)
- **pkg-config**
- **SFML** 3

### Dependency Installation

```sh
# Arch
sudo pacman -S gcc pkg-config sfml

# Ubuntu / Debian
sudo apt install g++ pkg-config libsfml-dev

# Fedora
sudo dnf install gcc-c++ pkgconf-pkg-config SFML-devel
```
