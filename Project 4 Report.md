1. How does your new simulation work? Describe each new component.
The patient and doctor lookup feature allows the user to type a name and view information about that person. The user types in the full name, for example "Scott Wagner," and presses Enter. Information about that person shows on the screen. The user presses Esc to clear the search. This feature works by going through each of the B-trees to find the name in question.
